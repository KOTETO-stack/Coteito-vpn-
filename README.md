# Coteito-vpn-
# Авто VPN Подписка

Автоматически обновляемая VPN-подписка для обхода блокировок легальных сервисов (YouTube, Telegram, TikTok и др.).

## Возможности

- **Автообновление** — раз в час собирает, тестирует и фильтрует сервера
- **Только Hy2 и Trojan** — никаких устаревших протоколов
- **150 серверов** из 100+ проверенных источников
- **Максимальный пинг 500 мс**
- **DNS через AdGuard** — блокировка рекламы на YouTube
- **WARP** — защита WireGuard от утечек
- **Xray Reality** — маскировка трафика под обычные сайты
- **Белый список** — российские сайты (Яндекс, Госуслуги, Авито и др.) идут напрямую
- **Ускорение мессенджеров** — WeChat, BiP, WhatsApp через оптимальные маршруты
- **Tor-мосты** — встроены для дополнительной надёжности
- **Названия серверов** — Страна + Город + Флаг, всё на русском
