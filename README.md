# Karing VPN Subscription Builder

Проект для автоматического формирования и проверки подписки, совместимой с Karing на iOS.

## Цель

Система собирает конфигурации из разрешённых публичных источников, проверяет их техническую доступность и формирует итоговую подписку только из узлов, прошедших заданные проверки.

Проект ориентирован на:

- стабильность соединения;
- минимизацию DNS/IP-утечек;
- автоматическое удаление неработающих конфигураций;
- совместимость с Karing и поддерживаемыми форматами конфигураций;
- отсутствие сбора пользовательских данных.

## Принципы безопасности

1. Не передавать через тестовые запросы персональные данные.
2. Не сохранять содержимое пользовательского трафика.
3. Не хранить cookies, токены, пароли и другие секреты.
4. Проверять DNS и маршрутизацию отдельно от обычного ping-теста.
5. Проверять IPv4 и IPv6, когда они доступны.
6. Исключать узлы с нестабильным соединением или ошибками TLS.
7. Не считать сам факт доступности сервера доказательством его доверенности.
8. Логи должны содержать только техническую информацию, необходимую для диагностики.
9. Все опубликованные конфигурации должны проходить повторную проверку.
10. Секреты CI/CD и служебные ключи не должны находиться в репозитории.

## Архитектура

```text
sources/
    ↓
collector
    ↓
parser / normalizer
    ↓
validator
    ├── protocol check
    ├── connectivity check
    ├── latency check
    ├── TLS check
    ├── DNS leak check
    └── IPv4/IPv6 check
    ↓
filter
    ↓
deduplicator
    ↓
subscription generator
    ↓
public subscription
